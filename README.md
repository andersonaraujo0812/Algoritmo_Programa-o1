# Algoritmos e Estruturas de Repetição em Java 

Este repositório contém uma coleção de exercícios práticos desenvolvidos em **Java** para consolidar fundamentos de lógica de programação, condicionais e estruturas de repetição (`for`, `while`, `do-while`). Os projetos fazem parte da minha formação acadêmica no Senac SP.


## 🛠️ Tecnologias e Conceitos Utilizados
- **Linguagem:** Java (JDK 17+)
- **IDE:** Visual Studio Code (VS Code)
- **Ferramentas:** Git e GitHub para controle de versão
- **Conceitos:** Validação de entradas com `Scanner`, estruturas condicionais compostas (`if/else`), operadores lógicos e manipulação de variáveis acumuladoras/contadoras.
