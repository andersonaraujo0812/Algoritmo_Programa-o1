O programa deverá solicitar ao usuário que digite o nome de seus 5 livros favoritos. Após a entrada de todos os livros, o sistema deverá exibir a lista completa na tela, mostrando os títulos informados.

Objetivos da atividade:
Utilizar a classe Scanner para receber dados do teclado.
Armazenar informações em variáveis do tipo String.
Exibir informações na tela utilizando System.out.println().
Compreender o fluxo básico de interação entre usuário e programa.
